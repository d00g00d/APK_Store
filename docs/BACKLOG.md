# BACKLOG и Дорожная карта проекта ru.d00g00d.apkstore

Это план разработки нашего магазина приложений для автомобиля Lynk & Co 900.

## Фаза 1: Подготовка и изучение (Текущая)
- [ ] Изучить предоставленные файлы с интересными решениями от других приложений.
- [ ] Определить архитектуру приложения (как оно будет скачивать и устанавливать файлы).
- [ ] Настроить проект (подключить нужные библиотеки для работы с сетью и файлами).

## Фаза 2: Базовый интерфейс и логика (UI/UX)
- [ ] Настроить модульную архитектуру (каждая важная функция — это отдельный независимый блок кода).
- [ ] Создать главный экран (список приложений, большие кнопки для удобства за рулем).
- [ ] Настроить темную и светлую тему (Material 3).
- [ ] Реализовать систему логирования ошибок (запись в файл, чтобы потом можно было найти проблему без подключения кабеля).

## Фаза 3: Источник данных, Скачивание и Установка
- [ ] Настроить магазин так, чтобы список приложений (в формате JSON) и сами файлы загружались напрямую из релизов на GitHub (GitHub Releases).
- [ ] Сделать механизм скачивания APK файлов из интернета с кэшированием (чтобы работало без интернета).
- [ ] Реализовать установку приложений по приоритету с возможностью изменения порядка или отключения в приложении:
    1. Использование хуков (Pine/XPosed).
    2. Использование ADB (если доступно).
    3. Обычная установка (с подтверждением пользователя).

## Фаза 4: Адаптация под автомобиль и специальные функции
- [ ] Настроить корректную работу с несколькими экранами (MultiDisplay) — чтобы всплывающие окна и уведомления появлялись на нужном экране.
- [ ] Обеспечить безопасность при движении (отключать сложный ввод на ходу).
- [ ] Добавить функцию изменения DPI (масштаба интерфейса) для пропатченных (специально измененных) приложений.
- [ ] Добавить дополнительные функции развертывания приложений на весь экран (чтобы приложение занимало оба экрана: и водителя, и пассажира одновременно).

## Фаза 5: Тестирование и Релиз
- [ ] Провести тесты на самом автомобиле (или эмуляторе).
- [ ] Записать результаты в `docs/TESTING.md`.
- [ ] Подготовить первую версию к использованию.
